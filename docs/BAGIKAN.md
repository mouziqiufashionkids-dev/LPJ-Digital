## 4. Tips menjawab pertanyaan umum

**"Gratis beneran? Nominalnya apa?"**
Beneran gratis. Kode MIT — pakai, ubah, sebar sesuka hatya. Kami dapat
pahala, itu nominalnya 😄

**"Aku gaptek, bisa pasang?"**
Pakai panduan `docs/PANDUAN-SETUP-WEBSITE.md` — dibuat khusus tanpa
terminal. ±30–45 menit sekali jalan.

**"Aman nggak datanya?"**
Database punya panitia sendiri (Supabase akun sendiri), bukan server kami.
Kami tidak menerima data apa pun dari yang memasang.

**"Kalau ada error?"**
Buka issue di GitHub — atau tanya langsung, insya Allah dibantu.
